# TOWARI

この先を、ともにする人と。審査制婚活サービスの体験用アプリケーションです。

## 起動

Node.js 20.9 以上で実行してください。

```sh
pnpm install
pnpm dev
```

http://localhost:3000 で表示できます。本番モードは `pnpm build` のあと `pnpm start`。

## 開発コマンド

| コマンド | 内容 |
| --- | --- |
| `pnpm typecheck` | tsc による型チェック |
| `pnpm lint` / `pnpm format` | Biome による検査 / 自動修正 |
| `pnpm knip` | 未使用のファイル・export・依存の検出 |
| `pnpm test` | vitest による単体テスト |
| `pnpm e2e` | Playwright による E2E（事前に `pnpm build`、初回は `pnpm exec playwright install chromium`） |

GitHub Actions（.github/workflows/ci.yml）で push / pull request ごとに上記すべてを実行します。

## 実装

- Next.js App Router / TypeScript / React / Zod
- ホーム、プロフィール詳細、地域・価値観の絞り込み、年齢順の表示、お気に入り、お見合い希望一覧、マイプロフィール
- 入会申請の入力検証、保存、お気に入り操作、面談希望の資格検証は Server Actions で処理
- ランダムなセッションIDを HttpOnly / SameSite=Lax Cookie で管理。本番モードでは Secure を有効化
- データはサーバープロセスのメモリにのみ保存。24時間のセッション期限、またはプロセスの再起動で失われます
- 申請前は面談希望をサーバー側でも拒否。申請後は「審査完了後の希望」を保存するだけで、審査承認や連絡はできません
- 絞り込み・並べ替えなど、取得済みの架空会員の表示操作はブラウザ上で行います

## 本番化までに必要なこと

この実装は本番向け構成を意識したプロトタイプで、本番提供できる審査・認証サービスではありません。体験アカウントはパスワード認証や身元確認をしていません。掲載会員は架空で、人物写真は日本人の架空会員を表現したAI生成画像です。

本番では永続DB、正式な会員認証、本人・独身確認、審査担当者の管理画面、権限・監査ログ、レート制限、個人情報の保持・削除方針、通報・ブロックを実装してください。インメモリのため複数プロセス・サーバーレスでの共有や永続性は保証されません。現在は秘密情報や本人確認書類を収集しません。

人物画像は public/portraits に同梱し、生成プロンプトは同フォルダの PROMPTS.md に記録しています。ヒーローの背景画像は images.unsplash.com、フォントは Google Fonts を利用します。接続できない場合はフォールバックフォントで表示されます。

## ページ構成

App Router で各機能をページに分けています。

- `/`：ホーム（ヒーロー、入会申請への導線、おすすめのお相手）
- `/discover`：お相手を探す（価値観・地域の絞り込み、並べ替え）
- `/favorites`：お気に入りのお相手
- `/meetings`：面談を希望したお相手
- `/profile`：マイプロフィール

## 会員画面の切り替え

- 各ページそのまま：男性会員向け・女性のお相手6名を表示
- 各ページに `?view=men`：女性会員向け・男性のお相手6名を表示

画面上部で切り替えられ、切り替え時も現在のページを維持します。URLの表示モードはサーバー側で判定し、対象の会員データを渡します。お気に入り・面談希望は同じセッションに保存され、一覧とお気に入り件数は現在の表示対象に絞られます。切り替えても保存済みの内容は失われません。全12名とも架空のサンプルで、写真はAI生成です。
